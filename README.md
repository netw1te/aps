## Вариант 10: Система бронирования билетов в сети кинотеатров

| Код | Расшифровка |
|-----|-------------|
| **ИБ** | Источник бесконечного типа |
| **ИЗ2** | Равномерный закон генерации заявок |
| **П31** | Экспоненциальный закон обслуживания |
| **Д1О33** | Постановка в буфер на первое свободное место (без сдвига) |
| **Д1ОО2** | Отказ по приоритету источника (вытесняется заявка с наибольшим номером) |
| **Д2П2** | Выбор прибора по кольцу |
| **Д2Б5** | Выбор заявки: приоритет по номеру источника, заявки в пакете |
| **ОР1** | Автоматический режим — сводная таблица результатов |
| **ОД1** | Пошаговый режим — календарь событий, буфер, текущее состояние |

### Бизнес-домен

Сервер бронирования билетов в сети кинотеатров. Клиенты через мобильное приложение или кассы оформляют заявки на бронирование. Серверы проверяют доступность мест, резервируют их и формируют электронные билеты.

**Приоритет источников:** кассы (меньший номер) > мобильные приложения (больший номер).
